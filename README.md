# Advertising Sales Prediction (Linear Regression)

## Overview
This project predicts product sales based on advertising spend on TV, Radio, and Newspaper.

## Steps Performed
- Data Cleaning
- Outlier Removal (IQR)
- Feature Engineering
- Feature Scaling
- Linear Regression Model

## Results
- R² Score: 0.9897
- MSE: 0.2804

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Matplotlib
